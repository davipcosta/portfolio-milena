# Milena Nobre — Psicóloga Clínica

Site de [psi-milena.com.br](https://www.psi-milena.com.br), feito com [Next.js](https://nextjs.org).

## Rodando localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Direitos de uso

O **código** deste repositório pode ser consultado e usado como referência.

As **fotos** (`public/milena2.jpeg`, `public/milena3.jpeg`, `public/og-image.jpg`), os **textos** do site e o **nome e a identidade visual** de Milena Nobre pertencem a ela e **não podem ser copiados, reutilizados ou redistribuídos** sem autorização.
